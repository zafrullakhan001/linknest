Security (v1.6)

Bookmark lists are sent only to sites on the organisation allowlist (allowedOrigins in org-branding.json, plus the App link origin when branding is on). Other websites get no reply. Bookmark sync starts Off until you turn it on here.

This profile only — not other people

Chrome and Edge store bookmarks per browser profile on this PC. This extension can only read your bookmarks in this profile. It cannot reach another employee’s PC, another Windows login, or another Chrome/Edge profile. Guest Your Bookmarks stay in this browser; nothing is uploaded by the extension.

Do not share a signed-in Chrome profile or an unlocked session. Anyone using this profile can click Sync and import this profile’s bookmarks into the LinkNest page they have open.

How the Sync button talks to this extension

The app name you type in Branding is only a label. It does not connect Sync. Chrome’s extensions page name does not matter either.

What actually makes Sync work:

  1. This extension is installed in your Chrome/Edge profile, with the bookmarks permission allowed.
  2. Bookmark sync on the Sync tab is on. An OFF badge means it is disabled.
  3. You open the organisation LinkNest URL (that origin must be allowlisted). file:// pages never work.
  4. You click Sync on Favorites → Your Bookmarks (or Fetch in Favorites Organizer).

The handshake (not the name)

The page posts a window message BROWSER_LAUNCHER_GET_BOOKMARKS to its own origin. This extension replies with BROWSER_LAUNCHER_BOOKMARKS_LIST only if the site is allowlisted and sync is on.

Mass deploy (IT)

  • Edit org-branding.json: set enabled true, your name/logo, appUrl, and allowedOrigins to only your LinkNest origin(s). Remove localhost for production.
  • Force-install a packed CRX (or Edge add-on) per user via Intune / GPO. Do not rely on Developer mode.
  • Each user keeps their own Windows account and Chrome profile so they can only sync their own bookmarks.

If Sync fails

  • Reload this extension, then refresh the app page.
  • Turn Bookmark sync on here. Confirm the site origin is in allowedOrigins.
  • Or use Import HTML / Merge in Your Bookmarks.
