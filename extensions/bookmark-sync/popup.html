How the Sync button talks to this extension

The app name you type in Branding (LinkNest, ERP Landing, AdventHealth, …) is only a label. It does not connect Sync. Chrome’s extensions page name does not matter either.

What actually makes Sync work:

  1. This extension is installed in the same browser as the app, with the bookmarks permission allowed.
  2. Bookmark sync on the Sync tab is on (this popup). An OFF badge on the toolbar means it is disabled.
  3. You open the app over http:// or https:// (not a saved HTML file).
  4. You click Sync on Favorites → Your Bookmarks (or Fetch in Favorites Organizer).

The handshake (not the name)

The page posts a window message BROWSER_LAUNCHER_GET_BOOKMARKS. This extension’s content script hears it, reads chrome.bookmarks, and replies with BROWSER_LAUNCHER_BOOKMARKS_LIST. That is the same protocol Browser Launcher Pro uses, bookmarks only.

What Branding is for

  • Display name / logo — toolbar and this popup.
  • App name — the words in “Open … in this browser”.
  • App link — optional URL so that name is clickable. Use this so people do not guess the site.

If Sync fails

  • Reload this extension, then refresh the app page (required after every extension reload).
  • Turn Bookmark sync on here.
  • Or use Import HTML / Merge in Your Bookmarks.

Full guide in the app: Help → Guides → Bookmark Sync Extension.
