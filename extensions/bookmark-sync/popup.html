Security (v1.8)

Bookmark lists and OutSync writes are sent only to sites on the organisation allowlist (allowedOrigins in org-branding.json, plus the App link origin when branding is on). Other websites get no reply. Read-only (Sync) and Read-write (OutSync) start Off until you turn each one on here.

This profile only — not other people

Chrome and Edge store bookmarks per browser profile on this PC. This extension can only read and write your bookmarks in this profile. It cannot reach another employee’s PC, another Windows login, or another Chrome/Edge profile. Guest Your Bookmarks stay in this browser; nothing is uploaded by the extension. OutSync never deletes Chrome bookmarks.

Do not share a signed-in Chrome profile or an unlocked session. Anyone using this profile can click Sync or OutSync and import or write this profile’s bookmarks from the LinkNest page they have open.

How the Sync button talks to this extension

The app name you type in Branding is only a label. It does not connect Sync. Chrome’s extensions page name does not matter either.

What actually makes Sync work:

  1. This extension is installed in your Chrome/Edge profile, with the bookmarks permission allowed.
  2. Read-only and/or Read-write on the Sync tab is on. An OFF badge means both are disabled.
  3. You open the organisation LinkNest URL (that origin must be allowlisted). file:// pages never work.
  4. You click Sync or OutSync on Favorites → Your Bookmarks (or Fetch in Favorites Organizer).

The handshake (not the name)

The page posts a window message BROWSER_LAUNCHER_GET_BOOKMARKS to its own origin. This extension replies with BROWSER_LAUNCHER_BOOKMARKS_LIST only if the site is allowlisted and Read-only is on. OutSync posts BROWSER_LAUNCHER_PREVIEW_PUSH_BOOKMARKS first (preview, no writes), then optionally BROWSER_LAUNCHER_BACKUP_BOOKMARKS (v1.8.2+, Read-only or Read-write) before BROWSER_LAUNCHER_PUSH_BOOKMARKS when you Apply — only if Read-write is on. Nested folders (v1.8.3+) are created under Other Bookmarks → LinkNest → named folder → space. A URL is skipped only if it already exists in that destination folder.

Mass deploy (IT)

  • Edit org-branding.json: set enabled true, your name/logo, appUrl, and allowedOrigins to only your LinkNest origin(s). Remove localhost for production.
  • Force-install a packed CRX (or Edge add-on) per user via Intune / GPO. Do not rely on Developer mode.
  • Each user keeps their own Windows account and Chrome profile so they can only sync their own bookmarks.

If Sync or OutSync fails

  • Reload this extension, then refresh the app page. Nested folder OutSync (named folder + space subfolders) needs v1.8.3+. OutSync preview needs v1.8.1+; bookmark backup before Apply needs v1.8.2+. Incognito / InPrivate open needs v1.8.4+ and Allow in Incognito enabled for this extension. Full browser window (tabs, toolbar, menus) needs v1.8.5+.
  • Turn Read-only on for Sync, and Read-write on for OutSync. Confirm the site origin is in allowedOrigins.
  • Or use Import HTML / Merge / Export HTML in Your Bookmarks.
